# Vantix Documentation

This directory holds the documentation site source (built out in Phase 5). It is **not** a Maven
module.

Planned contents:

- `grammar.md` — the EBNF grammar spec for `schema.vx`, written **before** the parser.
- Error-code reference (`VX-####`) for the error-translation starter.
- CLI reference and configuration reference.

For the architecture, decisions, and roadmap, see the repository-root documents:

- [`README.md`](../README.md) — product overview.
- [`CONTRIBUTING.md`](../CONTRIBUTING.md) — build, standards, and module boundaries.
